## 4 Repositórios e Artefatos do Projeto

| Tipo de Artefato | Link | Descrição |
|---|---|---|
| Repositório de código | https://github.com/Fernando-Oli/viaja-mais | Repositório público com o código, as migrations do banco, os testes, a esteira de integração contínua e a documentação técnica. A versão avaliada é a branch `main`. |
| Protótipo de interface | https://claude.ai/artifact/5GGDo2PEXLKYQecpdUPakk | Protótipo navegável de alta fidelidade, na identidade Avori, com as telas em largura de celular e de computador. |
| Documento de especificação | https://github.com/Fernando-Oli/viaja-mais/tree/main/docs/pfc | Fontes deste documento, um arquivo por seção. |
| Planos de atividade | https://github.com/Fernando-Oli/viaja-mais/tree/main/docs/plans | Um plano por atividade, com o que testar e o que validar definidos antes da implementação. |
| Matriz de rastreabilidade | https://github.com/Fernando-Oli/viaja-mais/blob/main/docs/pfc/rastreabilidade.md | Ligação entre cada requisito, o código que o implementa e o teste que o verifica, gerada a partir das marcações no código. |
| Evidências | https://github.com/Fernando-Oli/viaja-mais/tree/main/docs/pfc/evidencias | Saídas de testes, cobertura, capturas de tela e métricas da esteira, organizadas por data. |
| Fontes dos diagramas | https://github.com/Fernando-Oli/viaja-mais/tree/main/docs/pfc/diagramas | Arquivos PlantUML de todas as figuras deste documento. |
| Aplicação em execução | https://viaja-mais.online/ | Aplicação publicada na Vercel, com acesso por cadastro e login. |
| Ambiente local | `npm run setup` | Sobe a aplicação na máquina do desenvolvedor com um único comando: inicia o banco em contêiner, aplica as migrations, carrega os dados de teste e gera o arquivo de ambiente. |
