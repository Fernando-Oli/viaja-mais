**Detalhamento:** condições de contorno, regras associadas, o que está fora do

---

Status permitidos: `Implementado` · `Parcial` · `Não iniciado`
Prioridade: `Alta` · `Média` · `Baixa`

`Implementado` só quando existe código **e** teste **e** o fluxo funciona ponta a
ponta. Meio-caminho é `Parcial`, com o que falta escrito no Detalhamento.
`Não iniciado` é resposta legítima — o template avalia coerência, não completude.

A skill `/rastreabilidade` falha se um requisito marcado `Implementado` não tiver
teste associado.
